# 📊 CUSTOMER ANALYTICS POWER BI DASHBOARD

### An interactive Power BI dashboard designed to analyze customer demographics, purchasing behavior, and segmentation metrics using custom UI canvas layouts and DAX functions.

---

# 📌 KEY FEATURES

### • Customer Segmentation Analysis: Dynamic filtering by demographics, customer groups, and purchasing history.
### • Custom UI/UX Canvas Layout: Designed with custom background assets (`customer_dashboard_background.png`) for an executive view.
### • Advanced DAX Measures: Key performance indicators covering customer lifetime value, transaction frequencies, and retention rates.
### • Data Storytelling: Clear visual layout optimized for fast business decisions and cohort analysis.

---

# 🛠️ BUILT WITH

### • Business Intelligence: Microsoft Power BI Desktop (`.pbix`)
### • Data Source: CSV Dataset (`Customer_Info.csv`)
### • UI/UX Design: Custom PNG layouts
